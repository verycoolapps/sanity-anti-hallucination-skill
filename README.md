<details>
<summary><b>🗄️ Database Security — Klik untuk lihat</b></summary>

<br/>

```diff
- SALAH (SQL Injection):
-   query = "SELECT * FROM users WHERE id = " + userId
-   db.query("SELECT * FROM users WHERE name='" + req.body.name + "'")

+ BENAR (Parameterized Query):
+   query = "SELECT * FROM users WHERE id = ?"
+   db.query(query, [userId])
+   // ORM: User.where(id: userId)
```

**Aturan Absolut:**
- ✅ SELALU gunakan parameterized query / prepared statement
- ❌ JANGAN PERNAH string-concat user input ke SQL
- ✅ Principle of least privilege untuk DB user
- ✅ Validate dan encode output untuk display

</details>

<details>
<summary><b>🔑 Secret Management — Klik untuk lihat</b></summary>

<br/>

```diff
- SALAH (Hardcoded Secret — INSTANT BREACH):
-   const API_KEY = "sk_live_abc123xyz456..."
-   const DB_PASSWORD = "mySecretPass123"
-   const JWT_SECRET = "super_secret_key"

+ BENAR (Environment Variables):
+   const API_KEY = process.env.API_KEY
+   const DB_PASSWORD = process.env.DB_PASSWORD
+   const JWT_SECRET = process.env.JWT_SECRET
+   if (!process.env.JWT_SECRET) throw new Error("JWT_SECRET not configured")
```

**Jika Terdeteksi Secret di Kode:**
```
⚠️  SECURITY ALERT — Hardcoded credential terdeteksi!
   1. ROTATE credential ini SEKARANG — anggap sudah compromised
   2. Remove dari source code
   3. Hapus dari git history (BFG Repo Cleaner / git filter-repo)
   4. Audit semua akses yang mungkin menggunakan credential ini
```

</details>

<details>
<summary><b>🔐 Authentication & Authorization — Klik untuk lihat</b></summary>

<br/>

```diff
- SALAH (IDOR + Missing Auth):
-   app.get('/api/documents/:id', async (req, res) => {
-     const doc = await Document.findByPk(req.params.id)
-     res.json(doc)  // Siapapun bisa akses dokumen siapapun!
-   })

+ BENAR (Auth + Ownership Check):
+   app.get('/api/documents/:id', requireAuth, async (req, res) => {
+     const doc = await Document.findOne({
+       where: { id: req.params.id, userId: req.user.id }
+     })
+     if (!doc) return res.status(404).json({ error: 'Not found' })
+     res.json(doc)
+   })
```

<details>
<summary><b>🌐 Input Validation & XSS Prevention — Klik untuk lihat</b></summary>

<br/>

```diff
- SALAH (XSS):
-   element.innerHTML = userInput
-   document.write(req.query.name)
-   res.send(`<h1>Hello ${req.query.name}</h1>`)

+ BENAR:
+   element.textContent = userInput         // textContent, bukan innerHTML
+   res.send(escapeHtml(`Hello ${req.query.name}`))
+   // Atau gunakan framework yang auto-escape (React, Vue, Angular)
```

**Checklist Input Validation:**
- ✅ Whitelist approach — define apa yang BOLEH, reject sisanya
- ✅ Validate: type + length + format + range
- ✅ Normalize unicode sebelum comparison
- ✅ Reject null bytes dalam string
- ✅ Limit request body / file size

**EPISTEMIC — Hallucination Patterns:**

| ❌ Anti-Pattern | 🔴 Consequence |
|----------------|----------------|
| 👻 Phantom Function Syndrome | Debugging a function that never existed |
| 💀 Ghost File Hallucination | Implementation based on file never read |
| 🕰️ Version Confidence Fraud | Architecture based on version that doesn't exist |
| 🎭 False Certainty Masking | Debugging time wasted in the wrong place |
| ✍️ Confident Completion Fabrication | Silent bugs from "complete" fake code |
| 📰 Recency Abuse | "Recently added" from model's POV ≠ user's reality |
| 🔄 Self-Contradiction Blindness | Inconsistent names, versions, logic in one response |

**SECURITY — Vulnerability Patterns:**

| ❌ Anti-Pattern | 🔴 Consequence |
|----------------|----------------|
| 💣 SQL Injection Opening | Full database compromise |
| 🔑 Hardcoded Secrets | Instant credential breach |
| 🔓 Missing Authentication | Unauthorized access to all data |
| ⌨️ Raw User Input in Shell | Remote Code Execution (RCE) |
| 📂 Path Traversal | Arbitrary file read / write |
| 🧂 Weak Password Hashing | Password database brute-forceable |
| 💉 XSS via innerHTML | Account takeover + data exfiltration |
| 🪪 IDOR Vulnerability | Access other users' private data |
| 🌊 Missing Rate Limiting | Brute force attack opportunity |
| 🗣️ Info Disclosure via Errors | Stack traces map the codebase for attackers |
